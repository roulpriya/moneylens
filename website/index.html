Full installation guide ↗
1

Add MoneyLens to your agent

With the Codex CLI installed, add the MoneyLens source from your terminal. Then open Plugins in Codex Desktop, choose the MoneyLens source, and install MoneyLens.

codex plugin marketplace add roulpriya/moneylens
2

Open your project and ask your agent

Open a local session in Codex Desktop, connect your email MCP provider, and paste this prompt.

↳

Use $setup to set up my spending report and daily updates.

3

Confirm your sources

Setup confirms it can read your statements, builds your first report, then asks how often to refresh.

4

Come back anytime

Run $automation to refresh or fix a category, or let your schedule handle it.

Codex setup guide ↗
1

Add MoneyLens to your agent

Install the plugin’s setup and automation workflows in your project folder. This installer needs Node.js 22.20+.

npx skills add roulpriya/moneylens --skill setup automation -a claude-code
2

Open Code in Claude Desktop

Pick a Local environment, open the same project folder, connect your email MCP provider, then start a session with this prompt.

↳

/setup Set up my spending report and daily updates.

3

Confirm your sources

Setup confirms it can read your statements, builds your first report, then asks how often to refresh.

4

Come back anytime

Run /automation to refresh or recategorize. Recurring updates work if your session has scheduling tools.

Claude setup guide ↗
1

Add MoneyLens to your agent

For agents that support Agent Skills and local commands: run this in your project folder with Node.js 22.20+, then choose your agent in the installer.

npx skills add roulpriya/moneylens --skill setup automation
2

Open the same project in your agent

Connect an email MCP provider that can read messages and attachments, then start a session that can run Python locally.

↳

Use the MoneyLens setup workflow to set up my spending report.

3

Confirm your sources

Setup confirms it can read your statements, builds your first report, then asks how often to refresh.

4

Come back anytime

Ask your agent to run the MoneyLens automation workflow. Without scheduling tools, just run it whenever you want fresh numbers.

Other agents guide ↗

Saved locally. Processed with your AI agent.

Your ledger and report are saved locally. Your AI host and email connector process the emails, statement content and transaction details needed to build and update your report, under their own policies and your account settings. PDF extraction, reconciliation and calculations run locally. Local storage does not mean all processing stays on your device.
